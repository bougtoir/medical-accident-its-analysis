# 術中体位アライメントツール (Surgical Pose Alignment Tool)

CT撮影時の体位（リファレンス）と術中体位を比較し、
差分を可視化・修正指示を行うツールです。

## ツール一覧

### 1. ArUcoマーカー版（推奨）`aruco_app.py`

ArUcoフィデューシャルマーカーを患者体表に貼付し、CT撮影時と術中の体位を比較します。

**利点:**
- カメラ角度に非依存（異なる方向から撮影しても比較可能）
- 高精度（マーカーの位置・回転を正確に検出）
- CT画像にも対応（放射線不透過マーカーと併用可能）

```bash
streamlit run aruco_app.py
```

### 2. マーカーレス版 `app.py`

MediaPipe Poseによるマーカーレス姿勢推定。同じカメラ角度からの撮影が必要。

```bash
streamlit run app.py
```

## セットアップ

```bash
pip install -r requirements.txt
```

## ArUcoマーカー版の使い方

### 事前準備
1. アプリのサイドバーからマーカーシートを生成・印刷
2. マーカーを患者の体表に貼付（推奨配置位置はアプリ内に記載）
3. 透明フィルムでマーカーを保護

### CT撮影時
4. マーカーが見える状態で体位写真を撮影（→リファレンス画像）

### 手術時
5. 術中体位の写真を撮影（→ターゲット画像）
6. 両画像をアップロードして体位のズレを確認・修正

### 推奨マーカー配置
| マーカーID | 貼付位置 |
|-----------|---------|
| 0 | 胸骨上端 |
| 1 | 左肩峰 |
| 2 | 右肩峰 |
| 3 | 左上前腸骨棘 |
| 4 | 右上前腸骨棘 |
| 5 | 剣状突起 |

## 表示の見方

| 色 | 意味 |
|----|------|
| 🟢 緑 | 許容範囲内（問題なし） |
| 🟡 黄 | 要注意（閾値付近） |
| 🔴 赤 | 要修正（大きなズレ） |
| 🔵 青線 | リファレンス位置（ゴースト） |

## 注意事項

- マーカーはフィルムで保護し、CT撮影から手術まで位置を維持すること
- 本ツールは参考支援ツールです。臨床判断は医師が行ってください
