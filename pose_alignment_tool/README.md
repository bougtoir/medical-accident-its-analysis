# 術中体位アライメントツール (Surgical Pose Alignment Tool)

CT撮影時の体位（リファレンス）と術中体位を比較し、
マーカーレスで差分を可視化・修正指示を行うツールです。

## 機能

- **マーカーレス姿勢検出**: MediaPipe Poseによる33点のランドマーク自動検出
- **関節角度比較**: 主要関節（肘・肩・股関節・膝・体幹・頭部）の角度差を計算
- **修正指示表示**: どの関節をどの方向に何度動かすべきか表示
- **オーバーレイ可視化**: リファレンス姿勢をゴースト表示し、差分を色分け
- **閾値設定**: 警告・要修正の閾値をカスタマイズ可能

## セットアップ

```bash
pip install -r requirements.txt
```

## 使い方

```bash
cd pose_alignment_tool
streamlit run app.py
```

ブラウザで http://localhost:8501 が開きます。

1. **リファレンス画像**: CT撮影時の体位写真をアップロード
2. **ターゲット画像**: 術中の現在体位の写真をアップロード
3. 解析結果を確認し、修正指示に従って体位を調整

## 表示の見方

| 色 | 意味 |
|----|------|
| 🟢 緑 | 許容範囲内（問題なし） |
| 🟡 黄 | 要注意（閾値付近） |
| 🔴 赤 | 要修正（大きなズレ） |
| 🔵 青線 | リファレンス姿勢（ゴースト） |

## 注意事項

- 全身が写った写真を使用してください
- カメラ位置（撮影角度）はできるだけ揃えてください
- 本ツールは参考支援ツールです。臨床判断は医師が行ってください

## 技術スタック

- [MediaPipe Pose](https://mediapipe.dev/) - Google の姿勢推定モデル
- [Streamlit](https://streamlit.io/) - Web UI フレームワーク
- [OpenCV](https://opencv.org/) - 画像処理
