# 特許明細書（出願用ドラフト）

## 発明の名称

食品の色彩情報に基づく調理タイミング判定装置、調理タイミング判定方法、およびプログラム

---

## 【書類名】明細書

---

## 【技術分野】

【0001】
本発明は、調理中の食品の表面色をリアルタイムに計測し、ユーザーが指定した目標色に到達したことを検知して通知する調理タイミング判定装置、調理タイミング判定方法、およびプログラムに関する。より具体的には、食品表面のRGBまたはRGBC色情報をCIE L\*a\*b\*色空間に変換し、文化的に定着した調理色表現（飴色、きつね色、ハシバミ色等）に対応する目標色との色差（ΔE）を算出して、目標到達を判定する技術に関する。

---

## 【背景技術】

### 従来技術1: オーブン内蔵型カメラシステム

【0002】
特許文献1（US 12,331,938 B2, BSH Hausgeräte, 2017/2025）は、オーブン庫内に設置されたカメラで食品を撮影し、褐変度（degree of browning）を判定するシステムを開示する。2つの異なる輝度条件で撮影した画像の差分を用いて環境光成分を除去する手法が記載されている。しかし、本技術はオーブン庫内に固定されたカメラを使用するため、フライパン、鍋、グリル、揚げ鍋等のオープントップ型の調理器具には適用できない。すなわち、オーブン調理以外の日常的な調理シーン（炒め物、揚げ物、焼き物）をカバーできない。

### 従来技術2: センサーフュージョンによる調理状態判定

【0003】
特許文献2（EP 4,563,897, Samsung Electronics, 2023）は、ガスセンサー、温度センサー、および画像センサーを融合して調理状態を判定するシステムを開示する。画像センサーから色データを取得する構成を含むが、色情報はセンサーフュージョンの一要素に過ぎず、色単独での調理タイミング判定および色名プリセットに基づくユーザーインターフェースは開示されていない。また、当該システムは調理機器一体型であり、既存の調理器具に後付けできる外付け型構成は開示されていない。

### 従来技術3: GAN合成画像による焼き加減制御

【0004】
特許文献3（US 12,050,662 B2, 2021）は、敵対的生成ネットワーク（GAN）を用いて生食品の画像から各焼き加減の合成画像を生成し、ユーザーが目標画像を選択して加熱を自動制御するシステムを開示する。本システムは高い計算資源（GPU）を必要とするAI画像生成に依存しており、組み込み機器での実装が困難である。また、色差の定量的判定（ΔE値）ではなく画像全体の類似度を用いるため、照明条件変動に対するロバスト性が不明確である。

### 従来技術4: トースター内蔵型光検出器

【0005】
特許文献4（US 10,165,896 B2）は、トースター内部にフォトダイオードを配置し、パンからの反射光の色変化を検知して加熱を制御するシステムを開示する。単一食品（トースト）専用であり、目標色のユーザー選択機能および複数食品への汎用性を持たない。

### 従来技術5: コーヒー焙煎度色判定アプリ

【0006】
非特許文献1（xade roast）は、スマートフォンカメラでコーヒー豆の色を撮影し、CIE L\*a\*b\*色空間で焙煎度を判定するアプリケーションである。CIE L\*a\*b\*色空間での色差判定という技術的着想は共通するものの、コーヒー豆の焙煎に特化しており、一般的な調理（炒め物、揚げ物、焼き菓子等）への適用は開示されていない。また、連続的なリアルタイム監視ではなくスナップショット撮影による単発判定であり、色変化の時系列追跡および到達予測機能を持たない。

### 従来技術6: 産業用インライン色彩計

【0007】
非特許文献2（入江株式会社 PPLB-600）は、食品製造ラインにおいてCIE L\*a\*b\*色空間でクッキー等の焼き色を検査する産業用装置である。高精度であるが数十万円以上の高価格であり、家庭用途への適用は経済的に不合理である。また、目標色をユーザーが調理色名で選択するインターフェースは開示されていない。

### 従来技術の課題の総括

【0008】
上記従来技術を総括すると、以下の全てを同時に満たす調理タイミング判定装置は存在しない：
- (A) 特定の調理機器に依存せず、任意の調理器具（フライパン、鍋、揚げ鍋、オーブン、グリル等）に対して汎用的に使用できること
- (B) 消費者が購入可能な価格帯（数千円〜数万円）であること
- (C) リアルタイムの連続監視により、食品の色変化を時系列として追跡できること
- (D) 文化的に定着した調理色表現（飴色、きつね色、ハシバミ色等）を目標色としてユーザーが直感的に選択できるインターフェースを有すること
- (E) 色差（ΔE）の時系列変化率に基づき、目標色到達を事前に予測して予告通知できること
- (F) 外付け型クリップオンデバイスとして既存の調理器具に後付けできること

## 【発明の概要】

### 【発明が解決しようとする課題】

【0011】
本発明は、以下の技術的課題を解決するものである：
1. 特定の調理機器に依存せず、フライパン・鍋・揚げ鍋等のオープントップ型調理器具を含む多様な調理シーンにおいて、食品の色変化に基づいて調理タイミングを判定すること
2. 文化的に定着した調理色表現（飴色、きつね色、ハシバミ色等）をCIE L\*a\*b\*色空間上の数値としてプリセット辞書に格納し、ユーザーが自然な言葉で目標色を選択できるインターフェースを提供すること
3. 色差（ΔE）の時系列変化率を追跡し、目標色到達を事前に予測して予告通知を行うことで、調理の過度な進行（焦がし等）を防止すること
4. 照明条件の変動に対してロバストな色判定を、低コストの色彩センサーで実現すること
5. 組み込み機器（マイクロコントローラ）上でリアルタイムに動作する軽量な色空間変換および色差計算を実現すること

### 【課題を解決するための手段】

【0012】
上記課題を解決するため、本発明は以下の技術的手段を採用する。

【0013】
第一に、色彩センサー手段として、RGBCセンサー（赤・緑・青・クリアの4チャネル）および/またはカメラモジュールを備え、食品表面の色情報を取得する。前記色彩センサー手段は白色LED照明を内蔵し、食品表面を一定の分光特性で照射することにより、外部照明条件（蛍光灯、LED電球色、LED昼白色、自然光等）の変動が色計測に与える影響を低減する。

【0014】
第二に、色空間変換手段として、前記色彩センサー手段から取得したRGBC値を正規化してsRGB色空間の値とし、sRGBからCIE XYZ色空間を経由してCIE L\*a\*b\*色空間に変換する演算を行う。前記変換にはD65標準光源を白色点として用いる。

【0015】
第三に、目標色プリセット辞書として、複数の調理色表現に対応する目標色データを格納する記憶手段を備える。各目標色データは、少なくとも色名（文化圏における慣用名）、CIE L\*a\*b\*色空間上の目標座標値（L\*目標値、a\*目標値、b\*目標値）、および到達判定閾値（ΔE閾値）を含む。前記色名には、日本語の調理色表現（きつね色、飴色、ハシバミ色、こんがり、べっこう色、焦がしバター色等）および対応する英語表現（golden brown、caramel、hazelnut等）を含むことができる。

【0016】
第四に、色差判定手段として、前記色空間変換手段により算出された現在のL\*a\*b\*値と、前記目標色プリセット辞書から読み出された目標L\*a\*b\*値との色差ΔEを算出する。前記ΔEは、ΔE = √((ΔL\*)² + (Δa\*)² + (Δb\*)²) により算出されるユークリッド距離である。前記ΔEが前記到達判定閾値以下となった場合に、目標色到達と判定する。

【0017】
第五に、時系列追跡手段として、前記色差ΔEの時系列データを環状バッファに蓄積し、ΔEの時間変化率（減少速度）を算出する。前記時間変化率に基づき、目標到達までの残りサイクル数を推定し、所定の閾値（例えば5サイクル）以下となった場合に、予告通知を発する。

【0018】
第六に、ホワイトバランス補正手段として、調理開始前にユーザーが白色基準面（白色の皿、紙等）を前記色彩センサー手段に提示することにより、白色基準のRGBC値を取得し、R/G/B各チャネルの補正係数を算出する。以降の色計測において、前記補正係数を乗算することにより、照明条件の色偏りを補正する。

### 【発明の効果】

【0019】
本発明によれば、以下の効果が得られる：
1. 特定の調理機器に依存しない外付け型構成により、フライパン、鍋、揚げ鍋、オーブン、グリル等のあらゆる調理器具において色ベースの調理タイミング判定が可能となる
2. 文化的に馴染みのある調理色名（飴色、きつね色等）をそのまま目標として選択できるため、温度や時間の数値指定に比べてユーザーの直感に即したインターフェースとなる
3. ΔEの時系列追跡による予測通知により、カラメルのように色変化が急速に進行する食品においても、目標色到達前にユーザーに準備を促すことができ、過度な調理（焦がし）を防止できる
4. ホワイトバランス補正により、照明条件の異なる様々なキッチン環境（蛍光灯、LED、自然光）で安定した色判定が可能となる
5. CIE L\*a\*b\*色差によるシンプルなアルゴリズムであるため、ESP32等の低消費電力マイクロコントローラ上でリアルタイムに動作可能であり、消費者向け価格帯（1万円程度）のデバイスで実装できる

## 【発明を実施するための形態】

### 実施形態1: クリップオン型色彩センサーデバイス（TONGE）

【0021】
図1を参照して、本実施形態に係る調理タイミング判定装置100の構成を説明する。調理タイミング判定装置100は、色彩センサー部110、マイクロコントローラ部120、表示部130、通知部140、および記憶部150を備える。

【0022】
色彩センサー部110は、RGBCセンサー111および白色LED照明112を含む。RGBCセンサー111は、可視光の赤（R）、緑（G）、青（B）、クリア（C）の4チャネルの光強度を計測する。本実施形態では、TCS3472型センサー（ams-OSRAM社）を使用する。TCS3472は内蔵IRカットフィルタにより赤外線成分を除去し、可視光領域のみを高精度に計測する。白色LED照明112はRGBCセンサー111に隣接して配置され、食品表面を一定のスペクトル分布で照射する。これにより、外部照明の色温度変動（2700K〜6500K）が色計測結果に与える影響を大幅に低減できる。

【0023】
マイクロコントローラ部120は、ESP32-S3（Espressif Systems社）またはこれと同等の処理能力を有するプロセッサを含む。マイクロコントローラ部120は、色彩センサー部110からI2Cバスを介してRGBC値を取得し、以下の処理を実行する：
(a) RGBC正規化処理: Clear値Cに対するR、G、Bの比率を算出して正規化RGB[0,1]値を得る
(b) ホワイトバランス補正処理: 事前に取得した白色基準補正係数を正規化RGB値に乗算する
(c) sRGB→XYZ変換処理: 逆ガンマ変換（逆sRGBコンパンディング）を適用した後、3×3変換マトリクス（D65準拠）を乗算してCIE XYZ三刺激値を得る
(d) XYZ→L\*a\*b\*変換処理: D65標準白色点（X_n=0.95047, Y_n=1.00000, Z_n=1.08883）で正規化し、CIE規定の非線形関数f(t)を適用してL\*、a\*、b\*を算出する
(e) ΔE算出処理: 目標プリセットのL\*a\*b\*座標と現在のL\*a\*b\*座標のユークリッド距離を算出する
(f) 到達判定処理: ΔE値が目標プリセットの閾値以下であるか否かを判定する
(g) 予測通知処理: ΔEの時系列を環状バッファ（容量N、例えばN=60）に蓄積し、前回ΔEと今回ΔEの差分から変化率を算出し、目標到達までの残りサイクル数を推定する

【0024】
表示部130は、タッチスクリーンディスプレイを含む。表示部130は以下の情報を表示する：
(a) プリセット選択メニュー: 記憶部150に格納された目標色プリセットの一覧を、各プリセットの代表色サンプル（L\*a\*b\*値からRGB逆変換して表示）とともに一覧表示する
(b) モニタリング画面: 現在の計測色（RGB565形式に変換して表示）、目標色、ΔE数値、ΔEのプログレスバー（初期ΔEに対する現在ΔEの比率で進捗を表示）、およびΔE時系列グラフを表示する
(c) 到達通知画面: 目標色名、到達時のΔE値、経過時間を表示する

【0025】
通知部140は、圧電スピーカーおよび/または無線通信モジュール（Wi-Fi、Bluetooth）を含む。目標色到達時に所定の音響信号（例えば880Hzと1100Hzの交互二重音）を出力する。予告通知時には、到達時とは異なる短い音響信号（例えば660Hz、100ms）を出力する。無線通信モジュールを介して、外部のスマートフォンアプリケーションに通知を送信することもできる。

【0026】
記憶部150は、不揮発性メモリ（フラッシュメモリ）を含み、目標色プリセット辞書を格納する。図3に示すように、各プリセットレコードは以下のフィールドを含む：
- 色名日本語（例: "きつね色"）
- 色名英語（例: "Golden Brown"）
- 目標L\*値（例: 68.5）
- 目標a\*値（例: 12.3）
- 目標b\*値（例: 42.1）
- ΔE閾値（例: 6.0）
- カテゴリ（例: "揚げ物・焼き物"）
- 推奨調理例リスト（例: ["天ぷら", "唐揚げ", "とんかつ"]）

### 実施形態2: スマートフォンアプリケーション

【0029】
第二の実施形態として、スマートフォンのカメラを色彩センサー手段として利用する構成を説明する。スマートフォンにインストールされたアプリケーション（TONGINT）が、カメラからのリアルタイム映像フレームを取得し、ユーザーが指定した関心領域（ROI）内の画素の平均色を算出する。以降の処理（sRGB→L\*a\*b\*変換、ΔE算出、到達判定、予測通知）は実施形態1と同一である。

【0030】
本実施形態では、ホワイトバランス補正として、調理開始前に白色の皿または紙をカメラで撮影し、撮影画像のROI内平均RGB値を白色基準として取得する。この白色基準に基づく補正係数を算出し、以降のフレームに適用する。

【0031】
スマートフォンを三脚またはスタンドに固定し、調理面を連続的に撮影する構成とすることで、リアルタイム連続監視を実現する。

### 実施形態3: ΔE変化率に基づく予測通知

【0032】
図5を参照して、予測通知の動作を詳細に説明する。環状バッファに蓄積されたΔE時系列データにおいて、直前のサイクルのΔE値（ΔE_prev）と現在のΔE値（ΔE_curr）との差分Δrate = ΔE_prev - ΔE_currを算出する。Δrate > 0（ΔEが減少中、すなわち目標色に近づいている）の場合、目標到達までの残りサイクル数cycles_leftを以下の式で推定する：

```
cycles_left = (ΔE_curr - ΔE_threshold) / Δrate
```

cycles_leftが所定値（例えば5）以下となった場合、予告通知（プレアラーム）を発する。これにより、カラメル作りのように色変化が急速に進行する調理において、ユーザーが火力調整や取り出しの準備をするための時間的余裕を確保できる。

### 実施形態4: ホワイトバランス補正の詳細

【0033】
ホワイトバランス補正手段の具体的処理を説明する。キャリブレーション時に取得した白色基準のRGBC値を(R_w, G_w, B_w, C_w)とし、正規化した白色基準値を(r_w, g_w, b_w) = (R_w/C_w, G_w/C_w, B_w/C_w)とする。理想的な白色では r_w = g_w = b_w であるから、平均値avg = (r_w + g_w + b_w) / 3を算出し、各チャネルの補正係数を以下のように求める：

```
coeff_R = avg / r_w
coeff_G = avg / g_w
coeff_B = avg / b_w
```

以降の計測において、正規化RGB値(r, g, b)に対して(r × coeff_R, g × coeff_G, b × coeff_B)を適用した後にL\*a\*b\*変換を行う。

### 実施形態5: プリセット辞書の拡張・学習

【0034】
記憶部150に格納されるプリセット辞書は、ユーザーによるカスタムプリセットの追加が可能である。ユーザーが「この色が理想」と判断した時点でボタンを押すことにより、その時点の計測L\*a\*b\*値をカスタムプリセットとして登録できる。

【0035】
さらに、無線通信手段を介してクラウドサーバーに接続する構成において、複数ユーザーが登録したカスタムプリセットデータを集約し、統計的に処理（例えば中央値、四分位範囲の算出）することにより、プリセット辞書の目標L\*a\*b\*値を精緻化するクラウドソーシング型辞書更新機能を実現できる。

### 実施形態6: 相対色変化追跡モード

【0036】
絶対色ΔEによる判定に加え、食品の初期色からの相対変化量を追跡するモードを備える。調理開始時の食品色をL\*a\*b\*空間上の初期点として記録し、初期点からの累積移動距離または初期点と現在点を結ぶ方向ベクトルのL\*a\*b\*空間上の変位量を監視する。これにより、同一食品であっても品種、鮮度、カット形状等による初期色のばらつきに影響されない、相対的な調理進行度の判定が可能となる。

### 【要約】

【課題】
既存の調理機器は温度と時間のみで調理タイミングを制御しており、食品の色変化という直接的かつ信頼性の高い指標に基づく判定を行うものがない。

【解決手段】
色彩センサーで食品表面のRGBC値を取得し、CIE L\*a\*b\*色空間に変換して、プリセット辞書に格納された目標色（きつね色、飴色等の文化的調理色名に対応するL\*a\*b\*座標値）との色差ΔEを算出する。ΔEが閾値以下になった時点で通知し、さらにΔEの時系列変化率から目標到達を予測して予告通知を行う。
