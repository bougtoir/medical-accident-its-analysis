## 1. エグゼクティブサマリー

料理における「飴色」「きつね色」「ハシバミ色」等の色表現は、調理の出来栄えを示す重要な指標であるにもかかわらず、現行の調理機器は温度・時間のみでタイミングを制御している。本レポートでは、**食品の表面色をリアルタイムに計測し、目標色に到達した時点で通知する調理補助システム**の技術的実現可能性、特許状況、市場環境、および差別化ポイントを調査・整理する。

## 2. 背景：調理における「色」の意味

### 2.1 日本語の調理色表現

| 色名 | Hex | RGB | 調理での意味 | 対応する英語表現 |
|------|-----|-----|-------------|----------------|
| **きつね色** | #C48847 | (196, 136, 71) | 揚げ物・焼き物の理想的な仕上がり色。江戸時代から使用 | golden brown |
| **飴色** | #DEB068 | (222, 176, 104) | 長時間炒めた玉ねぎ等の深い褐色。水飴由来 | caramel / amber |
| **ハシバミ色** | #BFA46F | (191, 164, 111) | ナッツ類の自然な褐色。ヘーゼルナッツ由来 | hazelnut / light brown |
| **焦げ茶** | #6A4028 | (106, 64, 40) | 過度な加熱を示す暗褐色 | dark brown / burnt |

### 2.2 メイラード反応と色変化の科学

食品の褐変（browning）は主にメイラード反応（アミノ酸と還元糖の非酵素的褐変）によって生じる。この反応の進行度は：

- **温度**と**時間**の関数だが、食品の水分量・糖含有量・pH・アミノ酸組成によって大きく変動する
- つまり「何分加熱」「何度で加熱」では一律に制御できない
- **色変化こそがメイラード反応の直接的な観測量**であり、最も信頼性の高い指標

メイラード反応のモニタリングに関する学術研究（J-STAGE, ScienceDirect）では、RGB色空間やCIE L\*a\*b\*色空間での定量化が確立されている。特にL\*a\*b\*空間での色差（ΔE）が、反応進行度の指標として有用であることが示されている。

### 5.2 色空間とアルゴリズム

#### 推奨色空間：CIE L\*a\*b\*

- **L\*** = 明度（0=黒、100=白）
- **a\*** = 赤↔緑
- **b\*** = 黄↔青
- 人間の知覚に近い均等色空間であり、色差ΔEが知覚差に対応
- 食品科学で標準的に使用されている

#### 目標色判定アルゴリズム

```
1. キャリブレーション
   - 白色参照チップでホワイトバランス取得
   - 照明条件の補正パラメータ算出

2. リアルタイム計測ループ
   - 食品領域のセグメンテーション（背景除去）
   - RGB → L*a*b* 変換
   - 食品領域の平均色・色分布を算出

3. 目標色との比較
   - ΔE = sqrt((ΔL*)² + (Δa*)² + (Δb*)²)
   - ΔE < 閾値（例：5.0）で「目標色到達」と判定

4. 通知
   - ΔE の時系列トレンドを表示
   - 目標到達時にアラーム/プッシュ通知
```

#### 照明補正の重要性と手法

キッチンの照明条件（蛍光灯、LED、自然光、ガスコンロの炎）は大きく変動する。以下の補正手法が考えられる：

1. **リファレンスカラーチップ**：フレーム内に既知の色パッチを配置し、常に補正
2. **初期キャリブレーション**：調理開始前の生食品色を基準として相対変化を追跡
3. **分光センサー併用**：照明のスペクトルを別途計測し、反射光から照明成分を除去
4. **2輝度差分法**（BSH特許に類似）：光源の輝度を変えて2回撮影し、環境光成分を除去

5. 飴色に到達 → アラーム「飴色に仕上がりました！」

**シナリオ2：天ぷらの揚げ色管理**

3. カラメルの色変化は速いため、通知のタイミングが重要
4. 到達の5秒前に「もうすぐです」予告通知

### 7.2 知的財産の方向性

**独自性が主張できる要素**：
1. **色名プリセット辞書**：各国の調理色表現（飴色、きつね色等）を L\*a\*b\* 値にマッピングし、ユーザーが自然言語で目標を指定
2. **相対色変化追跡**：食品の初期色からの相対変化を追跡し、照明条件に依存しない判定を実現
3. **予測通知**：色変化の速度トレンドから目標到達時刻を予測し、事前通知を出す
4. **クラウドソーシング辞書**：ユーザーが「この色がベスト」と判定した時点の色データを収集し、色プリセットの精度を向上

## 8. リスクと課題

| リスク | 重要度 | 対策 |
|--------|--------|------|
| **照明条件の変動** | 高 | リファレンスチップ、相対色変化追跡、Phase 2で白色LED内蔵 |
| **蒸気・油煙によるカメラ曇り** | 高 | Phase 2でレンズ加温/防曇コーティング、撮影角度の最適化 |
| **食品セグメンテーションの精度** | 中 | フライパン/鍋の縁を検出して食品領域を推定。ユーザーによるROI指定 |
| **色の個人差（好み）** | 中 | カスタムプリセット機能。学習による個人適応 |
| **既存特許との抵触** | 中 | オーブン内蔵型ではなく外付け汎用型として差別化。プリセット辞書は新規性あり |
| **耐熱性（Phase 2）** | 中 | センサーはコンロ上方（レンジフード付近）に設置。直接加熱面には設置しない |
