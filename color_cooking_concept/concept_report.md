### 2.2 メイラード反応と色変化の科学

食品の褐変（browning）は主にメイラード反応（アミノ酸と還元糖の非酵素的褐変）によって生じる。この反応の進行度は：

- **温度**と**時間**の関数だが、食品の水分量・糖含有量・pH・アミノ酸組成によって大きく変動する
- つまり「何分加熱」「何度で加熱」では一律に制御できない
- **色変化こそがメイラード反応の直接的な観測量**であり、最も信頼性の高い指標

メイラード反応のモニタリングに関する学術研究では、RGB色空間やCIE L\*a\*b\*色空間での定量化が確立されている。特にL\*a\*b\*空間での色差（ΔE）が、反応進行度の指標として有用であることが示されている [1, 2]。

### 5.2 色空間とアルゴリズム

#### 推奨色空間：CIE L\*a\*b\*

- **L\*** = 明度（0=黒、100=白）
- **a\*** = 赤↔緑
- **b\*** = 黄↔青
- 人間の知覚に近い均等色空間であり、色差ΔEが知覚差に対応
- 食品科学で標準的に使用されている [2]

#### 目標色判定アルゴリズム

```
1. キャリブレーション
   - 白色参照チップでホワイトバランス取得
   - 照明条件の補正パラメータ算出

2. リアルタイム計測ループ
   - 食品領域のセグメンテーション（背景除去）
   - RGB → L*a*b* 変換
   - 食品領域の平均色・色分布を算出

3. 目標色との比較
   - ΔE = sqrt((ΔL*)² + (Δa*)² + (Δb*)²)
   - ΔE < 閾値（例：5.0）で「目標色到達」と判定

4. 通知
   - ΔE の時系列トレンドを表示
   - 目標到達時にアラーム/プッシュ通知
```

#### 照明補正の重要性と手法

キッチンの照明条件（蛍光灯、LED、自然光、ガスコンロの炎）は大きく変動する。以下の補正手法が考えられる：

1. **リファレンスカラーチップ**：フレーム内に既知の色パッチを配置し、常に補正
2. **初期キャリブレーション**：調理開始前の生食品色を基準として相対変化を追跡
3. **分光センサー併用**：照明のスペクトルを別途計測し、反射光から照明成分を除去
4. **2輝度差分法**（BSH特許に類似）：光源の輝度を変えて2回撮影し、環境光成分を除去

### 9.2 UnitV2 M12 の差別化要素

UnitV2 M12はパターンDの構成であり、他の構成と比較して以下の点で決定的に異なる。

#### M12レンズマウント — レンズ交換可能

| 構成 | レンズ | 交換 |
|------|--------|------|
| CoreS3 | GC0308 (0.3MP) 固定レンズ | 不可 |
| **UnitV2 M12** | GC2053 (2MP) + **M12マウント** | **自由に交換可** |

標準レンズ(FOV:85°)と魚眼レンズ(FOV:150°)が同梱。M12規格のレンズは数百円〜で大量に流通しており、広角（フライパン全体を近距離から）、マクロ（カラメル表面を拡大）、IRカット付き（色精度向上）等を用途に応じて換装できる。

#### LAB Color Tracker — ファームウェアレベルで標準搭載

```json
// LAB閾値を直接指定して色追跡
{
  "config": "Color Tracker",
  "l_min": 60,  "l_max": 80,
  "a_min": 125, "a_max": 145,
  "b_min": 155, "b_max": 185
}
```

CoreS3/Atomでは自前でRGB→L\*a\*b\*変換を実装する必要があるが、UnitV2ではJSON一行送るだけでLAB色追跡が動作する。

#### Linux環境 — 拡張性の桁違い

| 項目 | CoreS3 (ESP32-S3) | UnitV2 M12 (SSD202D) |
|------|-------------------|---------------------|
| **OS** | ベアメタル / RTOS | **Linux** |
| **CPU** | Xtensa LX7 240MHz | **Cortex-A7 Dual 1.2GHz** |
| **RAM** | 512KB + 8MB PSRAM | **128MB DDR3** |
| **OpenCV** | 使用不可 | **プリインストール** |
| **Python** | MicroPython（制限大） | **フルPython3** |
| **SSH** | 不可 | **可能** |
| **カメラ解像度** | QVGA (320×240) | **1080p (1920×1080)** |

OpenCVで食品領域セグメンテーション、色ヒストグラム分析（均一性判定）、時系列データCSV蓄積が可能。SSHで直接Pythonスクリプトを編集・実行でき、開発イテレーションが圧倒的に速い。

#### V-Training — カスタムAIモデル

M5StackのV-Trainingサービスで「きつね色の天ぷら」「飴色の玉ねぎ」「焦げすぎ」等のラベルで画像学習→UnitV2にデプロイ可能。LAB閾値だけでは捉えきれないテクスチャ・ムラ・泡立ち等の視覚的特徴も判定できる。

### 9.5 RGB → CIE L\*a\*b\* 変換（ESP32実装用）

```cpp
// TCS3472のRGBC値をCIE L*a*b*に変換する簡易実装
struct Lab {
    float L, a, b;
};

Lab rgb_to_lab(float r, float g, float b) {
    // 1. RGB → XYZ (sRGB, D65白色点)
    r = (r > 0.04045f) ? powf((r + 0.055f) / 1.055f, 2.4f) : r / 12.92f;
    g = (g > 0.04045f) ? powf((g + 0.055f) / 1.055f, 2.4f) : g / 12.92f;
    b = (b > 0.04045f) ? powf((b + 0.055f) / 1.055f, 2.4f) : b / 12.92f;

    float x = r * 0.4124564f + g * 0.3575761f + b * 0.1804375f;
    float y = r * 0.2126729f + g * 0.7151522f + b * 0.0721750f;
    float z = r * 0.0193339f + g * 0.1191920f + b * 0.9503041f;

    // 2. XYZ → L*a*b* (D65 reference)
    x /= 0.95047f; y /= 1.00000f; z /= 1.08883f;

    auto f = [](float t) -> float {
        return (t > 0.008856f) ? cbrtf(t) : (7.787f * t + 16.0f / 116.0f);
    };

    Lab lab;
    lab.L = 116.0f * f(y) - 16.0f;
    lab.a = 500.0f * (f(x) - f(y));
    lab.b = 200.0f * (f(y) - f(z));
    return lab;
}

float delta_e(Lab c1, Lab c2) {
    float dL = c1.L - c2.L;
    float da = c1.a - c2.a;
    float db = c1.b - c2.b;
    return sqrtf(dL*dL + da*da + db*db);
}
```
