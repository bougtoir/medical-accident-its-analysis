## 知財戦略の選択肢

### Option A: 国内特許のみ（最低限・低コスト）

| 項目 | 内容 | 費用概算 |
|------|------|---------|
| 国内出願 | 特許印紙代 | ¥14,000 |
| 電子出願 | オンライン手数料 | ¥2,400 |
| 弁理士費用 | 利用する場合（任意） | ¥20-40万 |
| 審査請求 | 出願から3年以内 | ¥138,000+（請求項数×¥4,000） |
| **合計** | 自力出願の場合 | **約¥16,400**（出願時） |

### Option B: 国内 + PCT国際出願（海外展開視野）

| 項目 | 費用概算 |
|------|---------|
| 国内出願 | ¥16,400 |
| PCT出願（12ヶ月以内） | 約¥30万 |
| 各国移行（30ヶ月以内、国ごと） | 1国あたり¥30-80万 |

### Option C: 国内出願 + 公開のみ（防衛目的）

出願するが審査請求せず、公開公報（出願から18ヶ月後に自動公開）により「公知技術」として第三者の権利化を阻止。費用は出願時の¥16,400のみ。

## 推奨: Option A → 状況に応じてB or C

1. **まず国内出願**（費用¥16,400、自力出願可能）
2. 論文投稿・反響を見て**12ヶ月以内にPCT判断**
3. 商業化見込みがなければ審査請求せず防衛公開

## 注意事項

### 新規性喪失を避けるために

| やってはいけないこと（出願前） | 理由 |
|-------------------------------|------|
| 論文をジャーナルに投稿 | 査読中でも公開扱いになりうる（電子公開日が起算点） |
| 学会で発表（口頭・ポスター） | 予稿集の発行日が公表日 |
| GitHub等でソースコードを公開リポに置く | 不特定多数がアクセス可能 → 公知 |
| ブログ・SNSで発明内容を公開 | 同上 |
| 守秘義務のない第三者に開示 | 秘密保持契約なしの開示は公然知られた発明 |

### やっても大丈夫なこと

| OK | 理由 |
|----|------|
| プライベートリポジトリでの開発 | 不特定多数にアクセスできない |
| 共同発明者間での議論 | 発明者間の開示は公知にならない |
| NDA締結済みの相手への開示 | 秘密保持義務下 |
| 特許出願後の論文投稿 | 出願日が先なので問題なし |
