# Network exclusion and state collapse — 96-case reclassification

This repository contains the reclassification of 96 polity-period cases for the
paper *Network Exclusion and State Collapse: From Maritime Isolation to
Technological Access Denial in the Long Run of History*.

The Public Choice decision (July 2026) treated the manuscript as a **de novo**
rejection: the editor and referees found the question interesting but concluded
that the classification framework was not transparent and the causal mechanism
was assumed rather than demonstrated. A new paper must therefore begin with a
pre-specified, source-anchored, blind-applied classification rubric.

## Files

- `rubric.md` — coding rubric and decision tree.
- `data/polity_period_records.csv` — legacy 96-case dataset from the original
  submission (includes the old `closure_type` values).
- `data/variable_metadata.csv` — description of each column in the legacy dataset.
- `data/classification_template.csv` — editable template for the new blind
  reclassification. Add `rater_closure_type`, `rater_confidence`, `rater_source_url`,
  `rater_source_ref` (printed canonical reference), `rater_source_quote`, and
  `rater_notes` for each case.
- `scripts/validate_classifications.py` — checks completeness and valid values in
  `data/classification_template.csv`.

## Workflow

1. Read `rubric.md`.
2. Fill in `data/classification_template.csv` row by row. Cite a specific source
   (`rater_source_url` and/or `rater_source_ref`) and quote the passage that
   justifies the classification. Do not look at the `outcome` column while coding.
3. Run `python scripts/validate_classifications.py` to check for missing or
   invalid entries.
4. Once all 96 cases are coded, run the script with `--summary` to identify the
   20–30 high-confidence cases for the sensitivity-analysis sub-sample.
5. The final reclassified CSV is then used to re-estimate the relationship between
   network exclusion and state collapse in the new manuscript.

## Data provenance

The legacy 96 cases were originally generated by Devin AI during earlier
sessions without record-level sources. This repository replaces that process
with a transparent, human-reviewed reclassification. The original values are
preserved in `legacy_closure_type` for comparison.
