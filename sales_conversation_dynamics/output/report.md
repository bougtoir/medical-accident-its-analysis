# 会話の発話量変化パターンと説得/成約の関係
## 目的

営業員/説得者の発話量（単語数/文字数）の時間的変化パターンが、成約や説得成功と関連するかを検討する。
フィラーの実データが得られないため、発話量をフィラーの代理指標として用いる。

## データセット

- **PersuasionForGood**（英語）: 1,017件の慈善寄付説得対話。寄付金額 `donation_ee` を指標に。
- **CyberAgentAILab/salestalk-dataset**（日本語）: 109件のB2Cセールス対話。購入意欲の前後差 `purchase_intention_change` を指標に。

## 方法

1. 各対話について、対話正規化位置（0=開始、1=終了）に対する発話量を二次関数でフィット。
2. 標準化した線形・二次係数の符号から、変化パターンを4種に分類：
   - `inverted_u`: 中盤にピーク（増加→減少）
   - `u_shape`: 中盤に谷（減少→増加）
   - `increasing`: 単調増加
   - `decreasing`: 単調減少
3. パターン別にアウトカムの分布を比較（Kruskal-Wallis、カイ二乗、回帰）。

## PersuasionForGood 結果

- 対話数: 1017
- Kruskal-Wallis H = 4.015, p = 0.260
- 形状別サマリー:

  - `decreasing`: n=18, 平均寄付=2.06, 中央値=0.15, 寄付率=0.611
  - `increasing`: n=32, 平均寄付=0.27, 中央値=0.00, 寄付率=0.406
  - `inverted_u`: n=884, 平均寄付=2.22, 中央値=0.05, 寄付率=0.543
  - `u_shape`: n=83, 平均寄付=2.36, 中央値=0.00, 寄付率=0.494

- 回帰（log1p 寄付金額）:
  - R² = 0.014, AIC = 2074.2
  - const: β=0.800, p=0.012, 95%CI=(0.176, 1.425)
  - linear_z: β=0.000, p=0.987, 95%CI=(-0.039, 0.039)
  - quadratic_z: β=-0.000, p=0.989, 95%CI=(-0.040, 0.039)
  - mean_value: β=-0.008, p=0.001, 95%CI=(-0.013, -0.003)
  - n_turns: β=-0.029, p=0.353, 95%CI=(-0.089, 0.032)

## CyberAgent salestalk 結果

- 対話数: 108
- Kruskal-Wallis H = 0.324, p = 0.955
- 形状別サマリー:

  - `decreasing`: n=8, 平均変化=1.00, 中央値=1.00, 改善率=0.750
  - `increasing`: n=8, 平均変化=0.62, 中央値=1.00, 改善率=0.625
  - `inverted_u`: n=82, 平均変化=0.71, 中央値=1.00, 改善率=0.561
  - `u_shape`: n=10, 平均変化=0.70, 中央値=1.00, 改善率=0.600

- 回帰（購入意欲変化）:
  - R² = 0.004, AIC = 367.4
  - const: β=0.603, p=0.368, 95%CI=(-0.720, 1.927)
  - linear_z: β=0.069, p=0.591, 95%CI=(-0.185, 0.324)
  - quadratic_z: β=0.050, p=0.672, 95%CI=(-0.184, 0.284)
  - mean_value: β=0.003, p=0.871, 95%CI=(-0.028, 0.033)
  - n_turns: β=-0.001, p=0.971, 95%CI=(-0.028, 0.027)

## 結論

- 主な発話量パターンは **inverted_u**（中盤に情報提供が集中し、終盤に絞る）であった。
- 想定された `decreasing` パターン（序盤に多く、徐々に減少）は少数で、統計的に優位な成約効果は確認されなかった。
- 両データセットで、発話量変化パターンとアウトカムの関連は弱く、統計的有意差は得られなかった。
- 発話量はフィラーの不完全な代理指標であるため、今後は音声付き実データでフィラーや発話速度を直接検証する必要がある。
