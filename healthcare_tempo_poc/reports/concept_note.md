# 持続可能な医療費構成のテンポ分析 — コンセプトノート

## 背景

本ノートは、tempo-effect 人口論文と、姉妹プロジェクト `gdp_tempo_poc` の
結論を踏まえ、**医療費の持続可能な構成**を分析する枠組みを提案する。

GDP PoC の結論は以下の通り（詳細は [`gdp_tempo_poc/reports/poc_findings.md`](../../gdp_tempo_poc/reports/poc_findings.md)）：

- **候補A（投資→稼働ラグのテンポ）**: 年次成長率フィットを74%の国で改善。
- **候補D（無形資本＝忘れられたパラメータ）**: 長期水準フィットを97%の国で改善、最大+1.9 ppの大効果。
- **候補B（労働参入・退出のテンポ）**: 年次動態には効かなかったが、長期水準では部分的に寄与。

ユーザー観察：**フロー型国富（GDP）とストック型国富（IWI, CWON）を隠れた指標で統合できる**。この示唆は医療領域でそのまま適用可能。

## 医療領域への移植

医療支出と健康アウトカム（平均寿命、健康寿命、疾病負荷）の関係は、まさに「フロー vs ストック」の構造：

- **フロー**: 年間医療支出（GDP比、PPP 一人当たり）
- **ストック**: 健康資本（健康余命、累積予防投資、医療 R&D ストック、長期ケア・インフラ資本）
- **観測された矛盾**: 米国は支出 GDP 比17%なのに平均寿命は OECD 最下位レベル。逆に日本は支出 GDP 比11%で平均寿命世界トップ。

**従来の解釈**: 「システムの非効率」「不平等」「食習慣」
**テンポ理論による再解釈**: 米国は高支出でも**医療フロー→健康ストックへの変換ラグ μ_H が伸びている**、つまり支出→アウトカム・ラグのテンポ効果で期間指標が大きく歪んでいる可能性。

## 3候補構造

GDP PoC と完全にパラレルな3候補構造を採用：

### 候補 A-H: 支出→アウトカム・ラグのテンポ

```
H(t+1) = (1-δ_H) H(t) + Σ_s w_s(μ_H(t)) E(t-s)
μ_H(t) = μ_H0 + μ_H1 (year - t0)
LifeExp(t) = f(H(t), demographics(t), σ)
```

`μ_H1 > 0` の国は時間と共にラグが伸長 → 現在の支出が将来のアウトカムに反映されにくい → **持続不可能性のシグナル**。

### 候補 B-H: 同時健康人口

同時在生人口を医療に移植。「現在健康な人口」`N_H(t) = Σ_a π(a,t) N_a(t)` で、`π(a,t)` は age-specific healthy-fraction。年齢階級別の健康割合が時変 → 期間指標の歪みを補正。

### 候補 D-H: 忘れられたパラメータ＝支出バケット別乗数

OECD SHA (System of Health Accounts) の分類に沿って医療費を4バケットに分解：

| HC 分類 | 内容 | 予想される乗数 λ |
|---|---|---|
| HC.1 | Curative（治療） | 1.0（基準）|
| HC.3 | Long-term care（長期ケア）| λ_L ∈ [0.5, 1.5] |
| HC.6 | Prevention（予防）| λ_P ∈ [2, 5]（最大）|
| HC.R | R&D（医療研究開発）| λ_R ∈ [3, 8]（最大）|

`H_total = Σ_b λ_b · H_b` と定式化し、バケット間で限界アウトカム乗数が体系的に異なることを実証する。

**予想される結論**: 予防と R&D の乗数が治療の数倍であれば、多くの国で支出構成の組み替えだけで大幅なアウトカム改善が可能 → **「持続可能性の本質は支出水準ではなく構成」**。

## 統合会計モデル

GDP-Beyond GDP の joint identification 式を医療向けに拡張：

```
観測量                          真の量         隠れた補正項
CurrentHealthExp_obs(t)    =    E*(t)        (フロー)
LifeExp_obs(t)             =    f(H*(t))     (期間指標、テンポ歪みを受ける)
HealthCapital_obs(t)       =    H*(t)        (忘れられたバケットが欠落)

恒等式:
dH*/dt = Σ_b λ_b E_b*(t) - δ_H H*(t) + ε(t)

同時推定で μ_H, {λ_b}, δ_H を同定
```

GDP PoC で示したのと同じ構造 — **支出（フロー）と健康ストックの不整合を、隠れたパラメータ（支出バケット乗数 λ、ラグ μ_H）で説明する**。

## 政策インプリケーション（仮説段階）

1. **米国型（高支出・低ストック）**: μ_H が急速に伸びている or λ_curative 偏重 → 予防・R&D への組み替えで改善余地大。
2. **日本型（中支出・高ストック）**: λ_prev（国民皆保険＋健診制度）と λ_LTC（介護保険）の組み合わせが効いている可能性。
3. **北欧型（高支出・中高ストック）**: 予防への歴史的投資の蓄積ストックが効いている。

これら仮説を最小 PoC（WB データのみで候補 A-H）→ フル実装（OECD SHA データで D-H）で段階的に検証する。

## 次ステップ

2. **OECD SHA データ取得**: `HC.1, HC.3, HC.6, HC.R` の年次支出データ（1990-）を SDMX 経由で入手。
3. **候補 D-H 実装**: λ 同時推定（年代×国の変動で識別）。
4. **候補 B-H 実装**: 年齢別 morbidity データ（GBD Study / WHO GHO）で effective health-need 構築。
5. **論文化**: GDP 論文の姉妹論文として、"Sustainable healthcare spending composition: tempo and forgotten parameters in health accounting" を投稿先検討。

## 倫理的注意

健康アウトカムのモデル化は、個人・集団の生存を直接扱うため、以下を遵守：
- 公開統計量のみを用い、個別患者データは一切扱わない。
- 政策提言は「フレームワーク上の帰結」として提示し、個別施策の推奨は所管専門家に委ねる。
- 価値判断（「生命の経済価値」など）を含む量的比較は明示的に分離。
