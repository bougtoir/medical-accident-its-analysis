# 製品設計書: ポータブルデカフェサシェ「caffe-out」

## 製品コンセプト

**「どんな飲料でも、持参したサシェでカフェインを out」**

モンモリロナイト（粘土鉱物）のカフェイン選択吸着能を活用し、消費者が任意のカフェイン含有飲料に浸漬するだけでデカフェ化できるポータブルサシェ製品。ブランド名「caffe-out」は、外出先（cafe）でもカフェイン（caffeine）を out できるという趣旨に由来する。

### 主要ターゲット

カフェインを控えたい**周産期・授乳期の母親**を第一ターゲットとし、安心・やさしさ・食品安全性を前面に打ち出す。ベントナイト（モンモリロナイト主成分）はFDA GRAS／EU E558／日本の食品衛生法で使用が認められた天然鉱物であり、合成吸着材を用いないことを訴求する。

### 形状設計（テトラ型の採用理由）

従来案の平型サシェ（60×80 mm）はティーカップ（開口内径70-80 mm）からはみ出し、飲用容器内での使用に不向きであった。本製品では以下の理由から**テトラ（四面体）型**を採用する:

- **容器内収まり**: 底面33 mm角のテトラ型はティーカップ・マグカップ内に完全に収まる。
- **接触効率向上**: 平型が飲料中で折れ曲がって接触面積が減るのに対し、テトラ型は立体形状を保持し吸着材全面が液と接触、かつカップ底部で対流を促す。同一充填量（5 g）で拡散律速下のカフェイン吸着速度が向上（実施例7: 平型88% → テトラ型92%／3分）。
- **製造技術の流用**: プレミアム紅茶で普及するナイロンメッシュ・テトラ充填の既存製造ラインをそのまま流用可能。

マチ付き平型（ガゼット）は、より多い充填量（8-10 g、マルチユース型）で採用する選択肢とする。

### バリエーション展開

1. **Tea用（緑茶・紅茶・烏龍茶）**: Na型MMT 5g — 安価・基本型
2. **Coffee用**: Al3+型MMT 5g — コーヒーのpHに最適化
3. **エナジードリンク用**: Al3+型MMT 8g — 高濃度カフェイン対応
4. **マルチユース型**: Al3+型MMT 10g — 2-3回使用可能（密閉保存袋付き）

## 製造プロセス

### 原料調達
1. **モンモリロナイト原鉱**: 山形県産ベントナイト（純度>90% MMT）
   - 代替: ワイオミング産 Na-ベントナイト（SWy-2相当品）
   - 食品添加物グレード品を使用（重金属規格適合品）

### 製造工程
```
原鉱採掘 → 精製（不純物除去）→ イオン交換処理*
→ 洗浄 → 乾燥（105℃） → 粉砕・分級（0.1-0.5 mm）
→ 品質検査（XRD, ICP-OES） → サシェ充填 → ヒートシール
→ 個包装（アルミラミネート） → 箱詰め → 出荷

*PRO版のみ: 0.1M AlCl3溶液で24時間イオン交換 → 純水洗浄3回
```

### 品質管理項目
- カフェイン吸着容量試験（ロットごと）
- 重金属溶出試験（Pb, As, Cd, Hg）
- Fe溶出量試験
- 微生物試験（一般生菌数、大腸菌群）
- 包材強度試験（サシェ破れ防止）

## 規制対応

### 日本
- **食品衛生法**: ベントナイトは「食品添加物（加工助剤）」として既存添加物名簿に収載
- **食品用器具・容器包装**: ポリプロピレン不織布は食品用途認可済み
- **表示**: 「食品加工助剤」として表示不要（最終製品に残存しないため）
  - ただしサシェ自体は「雑貨」扱いの可能性 → 食品衛生法上の位置付け確認要

### FDA (米国)
- ベントナイト: GRAS (21 CFR 184.1155)
- 用途: Processing aid, no limitation other than cGMP
- FCN (Food Contact Notification) は不要の可能性（GRAS物質のため）

### EU
- ベントナイト: E558（食品加工助剤）
- Regulation (EU) No 231/2012で規格規定

### 知財リスク評価
- **US 10,813,375 B2** (Decafino): 架橋ポリマー系 → 本発明はMMT（天然鉱物）のため非抵触
- **キリン特許群**: 工業的製造方法に関する特許 → 消費者用サシェ形態は用途・構成が異なる
- **自由実施可能性**: 高い（MMTのカフェイン吸着自体は自然現象、サシェ形態は公知）
  - ただし、イオン交換MMT＋特定包材＋インジケータの組合せは新規
