# Reproducibility test plan: researcher_mobility_ode

## Scope
Run the cached-data ODE pipeline on branch `devin/researcher-mobility-ode` and verify the baseline and new endogenous-inflow model produce the expected outputs, stable equilibria, and the spot-checked elasticity signs/magnitudes.

## Assumptions
- Repository root: `/home/ubuntu/repos/wip`
- Working directory for commands: `/home/ubuntu/repos/wip/researcher_mobility_ode`
- Python 3.10+ with `numpy`, `scipy`, `pandas` installed.
- Cached cohort files present:
  - `data/cohort/cohort.csv`
  - `data/cohort/transition_rates.csv`
  - `data/cohort/raw_sampled_works.json`
  - `data/country_civilization_mapping.json`
- No live OpenAlex calls are needed.

## Steps and pass/fail criteria

### 1. Environment sanity
Command: `python - <<'PY'` import `sys`, `numpy`, `scipy`, `pandas`, print versions.
- **Pass**: imports succeed, Python >= 3.10, numpy/scipy/pandas all available.

### 2. Baseline ODE run
Command: `python src/ode_model.py > test_outputs/baseline_run.log 2>&1`
- **Pass**: exit code 0, no traceback.
- **Pass**: `results/intervention_summary.md` exists and is non-empty.
- **Pass**: `results/equilibrium_summary.csv` exists and contains exactly 9 rows (one per civilisation group).
- **Pass**: in `results/equilibrium_summary.csv`, for every row `T_equilibrium > M_threshold` (equivalently `margin_to_threshold_T > 0`).
- **Spot-check (baseline)**: the printed summary shows all nine `T_eq` values and they are greater than the corresponding `M` values.

### 3. Endogenous ODE run
Command: `python src/ode_model_endogenous.py > test_outputs/endogenous_run.log 2>&1`
- **Pass**: exit code 0, no traceback.
- **Pass**: `results/endogenous/` contains:
  - `equilibrium_summary.csv`
  - `sensitivity.csv`
  - `point_of_no_return.csv`
  - `intervention_summary.md`
- **Pass**: `results/endogenous/equilibrium_summary.csv` contains exactly 9 rows.
- **Pass**: for every row, `T_equilibrium > M_threshold` (`margin_to_threshold_T > 0`).

### 4. Stability (all negative eigenvalues) check
Run a short verification script (temporary, no source changes) that, for each of the 9 civilisations:
- loads `transition_rates.csv` and `cohort.csv`,
- replicates the `r_use` computed by `ode_model_endogenous.py` (cap at `0.5 * r_critical`),
- builds the 6x6 matrix with `r_use`,
- asserts `max(real(eigvals(M))) < 0`.
- **Pass**: all 9 groups have strictly negative leading eigenvalue.

### 5. Spot-check endogenous elasticities
From `results/endogenous/sensitivity.csv`, filter `group == 'Japanese'`, `target == 'domestic_active'`:
- **Pass**: `p_D` elasticity is positive and within `0.20` to `0.25` (expected ~0.23).
- **Pass**: `d` elasticity is negative and within `-2.5` to `-1.8` (expected ~-2.0 to -2.3).

## Artifacts to collect
- `test_outputs/baseline_run.log`
- `test_outputs/endogenous_run.log`
- `test_outputs/eigenvalue_check.log` (or stdout captured)
- Any generated CSV/MD under `results/` and `results/endogenous/` (they will be regenerated by the run).
