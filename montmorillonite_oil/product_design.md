# 製品設計書: 天ぷら油復活サシェ「CLAYPOT」（仮称）

## 製品コンセプト

**「いつもの油を、いつもより長く」**

酸活性化モンモリロナイト（活性白土）の極性成分選択吸着能を活用し、使用済み食用油にサシェ（ティーバッグ型）を浸漬するだけで油脂品質を化学的に復元する使い捨てサシェ製品。デカフェサシェ「DECLAY」と同じ使用方法・製造技術基盤。

---

## ターゲット市場

### 一次ターゲット
- 天ぷら・揚げ物を週1回以上調理する家庭（日本の約40%）
- 油の使い回しに品質面の不安を持つ消費者
- 食用油のコスト削減を望む家庭

### 二次ターゲット
- 飲食店・惣菜店（フライ油交換頻度の低減）
- 食品廃棄削減・サステナビリティ志向の消費者
- アウトドア・キャンプでの揚げ物調理（携帯型）

### 市場規模
- 日本のオイルポット市場: 推定年間50億円（本体+交換フィルター）
- 日本の食用油市場: 約2,000億円/年
- 廃食用油: 年間約10万トン（家庭由来）

## 製造プロセス

### 原料調達
1. **モンモリロナイト原鉱**: 山形県産ベントナイト（純度>90% MMT）
   - 代替: ワイオミング産 Na-ベントナイト
   - 食品添加物グレード品（重金属規格適合品）
2. **活性白土**: 水澤化学工業 or 中央シリカから調達も可

### 製造工程
```
原鉱採掘 → 精製（不純物除去）
→ 酸活性化処理（4M HCl, 4時間, 80℃）
→ 水洗（pH中性になるまで）→ 乾燥（105℃）
→ 粉砕・分級（0.3-0.5 mm）
→ 品質検査（BET比表面積, 重金属, 酸残留）
→ サシェ充填（耐熱PP不織布）→ ヒートシール
→ タグ付き紐取り付け
→ 個包装（アルミラミネート）→ 箱詰め → 出荷
```

**既存製造技術の転用**: サシェの充填・シール工程はティーバッグ製造と同一設備で対応可能。耐熱性不織布はオイルポットフィルター業界に既に確立された部材である。

### 品質管理項目
- BET比表面積測定（ロットごと、≥250 m²/g）
- AV低減率試験（標準油での確認、≥30%）
- 重金属溶出試験（Pb, As, Cd, Hg: 食品衛生法規格）
- 酸残留試験（洗浄水pH: 6.0-8.0）
- 粒度分布（0.3-0.5 mm: ≥90%）
- 包材強度試験（サシェ破れ防止、油中浸漬30分後の健全性）
- 粒子脱落試験（浸漬後油中のMMT粒子検出なし）

## 規制対応

### 日本
- **食品衛生法**: ベントナイトは「食品添加物（加工助剤）」として既存添加物名簿に収載
- **食品用器具・容器包装**: PP不織布は食品接触用途認可済み
- **製品分類**: 「調理器具（キッチンツール）」として販売
  - 活性白土はサシェ内に留まり食品に残留しないため

### FDA (米国)
- ベントナイト: GRAS (21 CFR 184.1155)
- Food Contact Substance として適合

### EU
- ベントナイト: E558（食品加工助剤）
- Regulation (EU) No 231/2012 規格適合

## DECLAY（デカフェサシェ）との相乗効果

| 観点 | DECLAY（デカフェ） | CLAYPOT（油復活） |
|------|-------------------|-------------------|
| 吸着材 | Na/Al型MMT | 酸活性化MMT（活性白土） |
| 対象 | カフェインを飲料から除去 | 極性劣化物を油から除去 |
| 選択性 | カフェイン除去/ポリフェノール保持 | 劣化物除去/トリグリセリド保持 |
| 形態 | 同一（ティーバッグ型サシェ） | 同一 |
| 製造ライン | 共有可能（充填・シール工程） | 共有可能 |
| 規制 | 同一（GRAS/E558/既存添加物） | 同一 |
| ブランド | 「DECLAY」 | 「CLAYPOT」 |

**共通ブランド展開**: 「CLAY SERIES」としてシリーズ化し、ブランド認知の相乗効果を狙う。

### 競争優位性
1. **化学的品質復元**: 既存品が「物理的濾過」に留まるのに対し、「化学的復元」を実現
2. **産業実績100年**: 活性白土は食用油精製の世界標準技術
3. **食品安全性確立済み**: FDA GRAS / EU E558 / 日本既存添加物
4. **選択的吸着**: 劣化物のみ除去、油脂本体は95%以上保持
5. **簡便性**: ティーバッグのように浸漬するだけ、特別な器具不要
6. **環境貢献**: 廃食用油を最大50%削減
7. **DECLAYとの製造共有**: サプライチェーン効率化

## リスクと対策

| リスク | 影響度 | 対策 |
|--------|--------|------|
| 活性白土粒子の油中脱落 | 高 | 粒径/孔径比≥5の設計（0.3mm/50μm=6）+ 脱落試験 |
| 酸残留による油質劣化 | 高 | 洗浄工程の徹底（pH 6.0-8.0まで） |
| 重金属溶出 | 高 | ロットごとの溶出試験（Pb,As,Cd,Hg） |
| 浸漬時間の長さ（15-30分） | 中 | 「オイルポットに入れてそのまま放置」の使用法提案 |
| 消費者の効果実感の難しさ | 中 | 酸価試験紙同梱で「見える化」 |
| 特許クリアランス | 低 | 活性白土+油脂は汎用技術、サシェ形態が新規 |
| サシェからの油滴れ | 中 | 引き上げ後の一時置き用トレー同梱検討 |
