# ToMMo 試料・情報分譲 研究番号2025-0057 修正対応

## 研究課題
味蕾関連遺伝子多型が処方変更に与える影響の解明

## 審査結果
再審査（2026年5月29日通知）

## 修正コメント対応

### コメント1（科学的妥当性）— 修正・再審査を要する
> 候補薬が具体的に記載されていないため、交絡因子の選定が妥当かどうか不明です。

**対応**: 候補薬剤カテゴリ（①降圧薬 ②脂質異常症治療薬 ③消炎鎮痛薬 ④消化器用薬 ⑤糖尿病治療薬）を具体的薬剤名とともに追記。交絡因子の臨床的妥当性を説明。

### コメント2（科学的妥当性）— 修正・再審査を要する
> 目的とする薬剤感受性を検討するための処方変更を、調査票情報で捉えられるのか、インターバルが適切か、疑問です。また、目的から、調査対象は縦断的なデータを有する参加者に限る必要があるのではないでしょうか。統計解析に、GWAS解析を追加とありますが、今回は一部遺伝子領域のみ分譲のため、候補領域における関連解析のことでしょうか。

**対応**:
- 調査票（生活）情報の服薬情報（商品名、入手方法、使用期間、使用頻度、1回使用量）の2時点比較で処方変更を定義する旨を明記
- 両調査の間隔（約5〜7年）が慢性疾患の処方変更捕捉に十分な観察期間である旨を明記
- 解析対象者をベースラインおよび第2段階調査の双方に参加した縦断データ保有者に限定
- 「ゲノムワイド解析（GWAS）」→「候補遺伝子領域における関連解析」に修正

### コメント3（実行可能性）— 修正・再審査を要する
> 目的変数となる処方の増減についてどの程度のサンプルサイズが見込まれるのか記載されていないため、研究の実現性が不明です。

**対応**: 想定サンプルサイズを追記（dbTMM 2026 120Kリリースから縦断データ保有者約30,000〜40,000人、服薬情報保有者約20,000〜25,000人、処方変更有する者約5,000〜10,000人）。検出力80%以上を確保可能と記載。
